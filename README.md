# Global Pandemic Pulse

A React-based web application that visualizes global COVID-19 data using D3.js.

## Features

- Interactive world map showing COVID-19 cases and deaths
- Regional trend analysis
- Country-specific deep dive
- Time-based data exploration
- Global metrics dashboard

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## Technologies Used

- React 18
- D3.js
- TopoJSON

## Data Source

The application uses data from the World Health Organization (WHO), updated weekly.

## Project Structure

- `/src/components` - React components
- `/src/utils` - Utility functions and API calls
- `/src/assets` - Static assets and data files

## Development

The application is built with React and uses D3.js for data visualization. The main components are:

- WorldMap: Interactive global visualization
- RegionalTrends: Regional comparison charts
- CountryDeepDive: Detailed country-specific analysis
- GlobalMetrics: Key global statistics
- TimeSlider: Time-based data navigation
